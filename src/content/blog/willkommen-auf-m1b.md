Welcome to **m1b.de**! 

Under this name, **Moosauer IT Consulting** (Moosauer IT Beratung) served as a trusted partner for demanding IT projects, application architecture, and bespoke software solutions from 2000 to 2013. 

With the transition into optical metrology and software engineering (including at **ZEISS Optotechnik GmbH**), the challenges have evolved—ranging from distributed systems and modern web platforms to near-real-time robot control and industrial automation.

## What We Write About Here

This blog serves as a knowledge base and architecture notebook for modern IT topics:

- **Software Architecture & C# / .NET**: Clean code, event-driven systems, and high-performance application development.
- **DevOps & CI/CD**: Automated pipelines with GitHub Actions, containerization, and Infrastructure as Code.
- **Robotics & Industrial Automation**: Interfacing industrial robots and optical measurement systems in C#.
- **Modern Web**: Jamstack, Astro, TypeScript, and high-performance static portals.

## Static, Fast, and Modern

The new portal is built on **Astro**—a modern static site generator designed for maximum performance, accessibility, and minimal JavaScript overhead. Deployments run fully automatically via **GitHub Actions** on every commit to our development branch.

Stay tuned for hands-on tutorials, architectural insights, and code examples!
